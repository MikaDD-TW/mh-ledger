# MH 記帳本

M 和 H 的共用記帳 App。加到 iPhone 主畫面後像一般 App 一樣點開，帳直接存進 Google 試算表。

- 網址：https://mikadd-tw.github.io/mh-ledger/
- 資料在你自己的 Google 試算表，這個 repo 裡沒有任何帳目。沒有通行碼的人打開只會看到設定畫面。

## 安裝（只要做一次）

### 1. Apps Script 加上 Api.gs

1. 打開記帳的 Google 試算表 → 擴充功能 → Apps Script。
2. 左側「檔案」旁的 ＋ → 指令碼，檔名打 `Api`，把 [`apps-script/Api.gs`](apps-script/Api.gs) 整份貼上，儲存。Code.gs 不用動。
3. 上方函式選 `setupApp` → 執行。
4. 部署 → 管理部署作業 → 點鉛筆 → 版本選「新版本」→ 部署。/exec 網址不會變。

### 2. 兩支手機各自加到主畫面

1. 回到試算表「設定」分頁：B12 是 M 的連結，B13 是 H 的。
2. 用 iPhone 的 **Safari** 打開自己那條連結。
3. 分享 → 加入主畫面。

## 功能

- **記帳**：常用項目一點帶入、自動猜分類，加入後直接寫進試算表。
- **本月**：各分類額度剩多少，伙食每天可用多少。
- **鐵盒**：還沒從鐵盒拿錢的帳，按人分組一鍵結清。
- **更多**：從 LINE 文字匯入、連線狀態、換連結。
- 沒網路也能記，連上後自動補送。打開時先顯示上次的資料，不用等。
